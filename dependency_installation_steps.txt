# Steps to Install Dependencies After Cloning the Repository

1. **Navigate to the Project Directory**
   Open a terminal and navigate to the root directory of the cloned repository.

   ```bash
   cd path/to/cloned/repository
   ```

2. **Install Dependencies for Each Framework**

   - **Angular**:
     Navigate to the `angular` folder and install dependencies using `npm`:
     ```bash
     cd apps/angular
     npm install
     ```

   - **React**:
     Navigate to the `react` folder and install dependencies using `npm`:
     ```bash
     cd ../react
     npm install
     ```

   - **Svelte**:
     Navigate to the `svelte` folder and install dependencies using `npm`:
     ```bash
     cd ../svelte
     npm install
     ```

   - **Vue**:
     Navigate to the `vue` folder and install dependencies using `npm`:
     ```bash
     cd ../vue
     npm install
     ```

3. **Install Python Dependencies**
   Navigate to the `analysis` folder and install Python dependencies using `pip`:
   ```bash
   cd ../../analysis
   pip install -r requirements.txt
   ```

4. **Install Dependencies for Test Scripts**
   Navigate to the `test-scripts` folder and install dependencies using `npm`:
   ```bash
   cd ../test-scripts
   npm install
   ```

5. **Verify Installation**
   Ensure all dependencies are installed correctly by running the following commands in their respective directories:

   - Angular: `ng version`
   - React: `npm start` or `npm run build`
   - Svelte: `npm run dev`
   - Vue: `npm run serve`
   - Python: `python -m pip list`

6. **Optional: Run Tests or Experiments**
   Follow the instructions in the `README.md` or `test-scripts` folder to run tests or experiments.

---

**Note:** Ensure you have the following installed on your system:
- Node.js and npm
- Python and pip
- Any other tools mentioned in the `README.md` file.
